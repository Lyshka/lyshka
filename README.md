### About me

I build and maintain web projects across the full development cycle:
interfaces, backend logic, integrations, deployment and ongoing support.

- **WordPress:** custom themes and plugins, WooCommerce and API integrations.
- **Frontend:** responsive interfaces and web applications with React and Next.js.
- **Backend:** PHP, JavaScript, REST APIs and MySQL.
- **Infrastructure:** Linux servers, Nginx, Docker, caching and Cloudflare.
- **Performance:** investigating bottlenecks and improving loading speed and reliability.
